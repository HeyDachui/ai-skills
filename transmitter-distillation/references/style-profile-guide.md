# 传承者·蒸馏｜风格 Profile 指南

风格 Profile 是运行时创作指南，不是人物传记，也不是原文仿写模板。它应能指导一篇新的文章、一个新的脚本或一个新的创作 brief，同时让使用者知道何时不能套用。

## 推荐结构

```markdown
# [研究对象]｜迁移型风格 Profile

## 适用场景
- 适合的题材、媒介和受众
- 不适合直接套用的场景

## 核心机制
### 机制一：...
- 作用：它改变了什么感受、理解或行动？
- 动作：创作者具体做什么？
- 条件：什么必须先成立？
- 代价：这样做会牺牲什么？
- 来源卡：card-id

## 写作／创作时的检查问题
- ...

## 失败信号与修复
- 信号：...
- 可能原因：...
- 修复：...

## 不要复制的表面
- 词壳、口头禅、固定意象或年代语境

## 迁移边界
- 已知可迁移的部分
- 未验证的部分
```

## Profile 的写法

- 用动作和判断顺序，不用“要有某某气质”作为唯一指令。
- 同时写“怎样做”和“什么时候不要做”。
- 把作者特有的生活经历标为来源事实，不能要求另一个使用者虚构同样经历。
- 保留强观点，但把判断对象、条件和证据写清楚。
- “不要古意”“不要口语”“不要夸张”等宽泛禁令必须改写成可观察的失败信号；同一手段在正确关系中可能是正向能力。
- Profile 内部可以提到来源卡 ID；公开成品不能暴露内部字段、证据定位或大段受版权保护的引文。

## 与创作成品的分离

先使用 Profile 完成成品，再做后置复核。不要在成品开头添加“以下只是分析”“尚未亲自使用”等内部声明来补救身份；身份、来源和未知放在成品外的工作记录中。若真实使用者身份尚未确认，成品中的亲历叙述要改成基于材料或原理的判断。
