# 传承者·蒸馏｜后置审计清单

审计只检查会改变当前产出的维度；不要因为还能找到更多书页就无限延长。

## A. 来源与阅读分母

- [ ] 每个来源有稳定身份、版本和材料类型。
- [ ] 已区分全量导航、代表性深读和未覆盖部分。
- [ ] 页码／时间码体系明确，不能把印刷页与 PDF 页混写。
- [ ] 每个证据摘录可以回到当前仍存在的来源或证据胶囊。

## B. 语义与证据

- [ ] 每个承重判断都有连续证据，不靠孤立金句。
- [ ] 来源观察没有混入 AI 解释。
- [ ] AI 解释没有冒充作者明说或研究事实。
- [ ] 主张强度没有超过证据承重范围。
- [ ] 具体效果、代价和因果关系分别有依据，或已收窄为假设。

## C. 机制与风格

- [ ] 卡片写的是作用关系、动作、条件和代价，而非表面词库。
- [ ] Profile 能让另一个创作者执行和自检。
- [ ] 失败信号可观察，修复动作具体。
- [ ] 传统资源、口语、幽默、夸张等手段没有被一刀切成负面。
- [ ] 保留了材料中的矛盾和反例。

## D. 去重与身份

- [ ] 每个主题只有一个去向：新卡、合并、扩展、项目资产或证据不足。
- [ ] 文章、风格 Profile、知识卡和原文来源没有互相冒充。
- [ ] 未把风格蒸馏 PASS 写成作者认可、跨题有效或已采用。

## E. 公开边界

- [ ] 公开成品不泄露内部路径、候选状态、页码字段或长引文。
- [ ] 具名对象的权利、授权和适用限制另行记录。
- [ ] 当代／在世创作者的输出采用高层机制与转化表达，不做可替代原作的逐句模仿。

## 裁决等级

- `PASS`：结构、证据、边界和去重均可接受。
- `LIGHT_REPAIR`：只需具名字段或局部主张收窄。
- `RETURN_INSUFFICIENT`：承重证据不足，不能靠润色补救。
- `NOT_A_VALIDATION`：只有静态回归或模仿样本，没有真实新输入或相称的专业反馈。
