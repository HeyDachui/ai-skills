# 传承者·蒸馏（transmitter-distillation）

从书籍、论文、访谈和作品材料中提炼可追溯的创作机制、风格卡与迁移边界。

## 这是什么

这是一个可复用的 AI Skill，用于把来源证据、作者判断、产生效果的机制、可迁移做法和不能越过的边界分层记录。它强调从作用关系提炼方法，不把表面词汇、口头禅或未经核实的传记当成“风格”。

本公开包只包含方法说明、参考合同和通用脚本，不包含任何具体艺术家的原文、作品素材、私人研究材料或内部蒸馏卡片。

## 使用

将整个 `transmitter-distillation` 目录复制到你的 AI 客户端 Skills 目录，然后使用 `$transmitter-distillation`。目录结构和参考文件需要一起保留；只复制 `SKILL.md` 会使参考与脚本入口不完整。

## 适用边界

- 适合研究创作者材料、构建风格卡、应用已完成的风格 Profile，以及审计来源、解释、迁移和模仿边界。
- 不用于批量复制未经授权的原文、伪造创作者亲历、把单篇作品冒充跨题规律，或生成可替代原作者的新作仿写。
- 审计通过只说明结构与证据边界合格，不代表作者本人认可、跨题创作有效或任何作品已被采用。
