# 双角色互动

仅在两个角色各自母版已经稳定时读取并使用。

## 1. 先定义关系

- A与B分别是谁、哪个母版版本有效；
- 谁先做动作，谁回应；
- 两者是同一角色双份、主副角色，还是两个独立角色；
- 体型差、性格差和品牌元素怎样区分；
- 本张表情要表达什么人际关系。

## 2. 互动成立条件

至少包含一种真实关系：接触、目光、递交、拉扯、保护、安慰、阻止、跟随、共同操作或共同目标。A的动作应改变B的状态，或B的反应应清楚回应A。

可用结构包括：抱抱、贴贴、哄、递纸巾、盖被子、一起工作、一方捣乱、击掌、拉走、偷看与回应、共同庆祝。它们是结构示例，不是固定动作清单。

## 3. 图像生成要求

双角色新画面仍属于角色形象生成，必须调用图像生成能力。每个角色分别绑定自己的唯一母版；互动参考只提供关系与构图，不得把参考中的角色身份迁入当前角色。

生成提示词应写清：

- A与B的母版和不可改变特征；
- 谁主动、谁回应；
- 接触点、目光、手势、身体重心和道具中心；
- 两个角色各自必须保持什么；
- 禁止穿透、额外肢体、比例漂移、并排摆拍和文字隔断关系。

## 4. 小尺寸判断

缩小后仍应看懂“谁对谁做了什么”。如果只能看见两个角色存在，却读不出关系，互动未通过。
