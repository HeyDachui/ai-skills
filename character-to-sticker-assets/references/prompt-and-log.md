# 提示词与线程记录

只在任务需要图像生成或图像编辑时读取。

## 1. 线程记录是不变要求

生成前，在当前任务对话中写出本轮实际提交的完整提示词。生成后补充输出ID或文件、选择结果和下一轮修正。项目内Markdown可以镜像同一内容，但不能替代线程记录。

## 2. 提示词结构

按真实需要组合，不为填字段添加无用句子：

1. 唯一母版身份与版本；
2. 其他参考图各自只负责什么；
3. 本轮只生成或修改什么；
4. 必须保持的角色特征；
5. 具体动作、情绪、视线、手势、身体重心和关系；
6. 品牌元素如何进入角色，不得遮挡脸或抢第一视觉；
7. 构图、透明背景、输出方式和小尺寸要求；
8. 禁止方向与本轮不允许改变的内容。

## 4. 通用生成骨架

```text
以Image A作为唯一角色母版。严格保持其脸型、眼睛比例、头身比、主色、关键结构、服装／包裹关系和整体气质。Image B只用于动作参考，Image C只用于品牌元素参考；不得把B或C的角色身份混入A。

本轮只生成：……

动作与情绪：说明角色正在做什么、为什么、面对谁、身体重心、视线和手势怎样变化。

输出要求：透明背景、单个表情独立、主体完整、小尺寸仍能识别；需要文字时保持简短并避开脸与动作中心。

禁止：代码绘制替代角色、脸型漂移、混用旧版本、额外肢体、品牌元素遮脸、动作没有事件、文字掩盖互动、把技术拆件当正式成品。
```

## 5. 单变量返修

```text
继续使用同一母版、同一参考角色和上一轮已通过内容。本轮只修：……。

必须保持不变：……。

禁止同时改变其他变量。
```

返修后只检查本轮受影响维度；没有新问题就停止。
