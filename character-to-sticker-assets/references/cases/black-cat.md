# ChatGPT黑猫小杰案例

状态：`PUBLIC_TEXT_REFERENCE / PILOT_METHOD / NOT_A_MASTER / NOT_FORMAL`

## 事实

- 角色视觉来自实际图像生成；此前代码直接绘制的错误版本已废弃。
- 该案例曾覆盖图像生成母版、表情、动作、动画拆件与真实可编辑源的分层边界。
- 公开版不附带内部图片、GIF、ORA源文件、上传状态或项目清单。
- 白结是独立包裹／道具，不是每张图固定头套。

## 值得复用的判断

- 当代码直绘造成身份和质感错误时，应废弃替代画法，回到图像生成母版。
- 正式母版、原貌保持Rig、技术组件Rig、表达切换、动作切换和平台导出必须分开。
- 真正可编辑的ORA可以复用；SVG若只是独立栅格对象必须标记为封装，不冒充真矢量。
- “没电、收到、工作、偷看、睡觉”等动作完成真实聊天任务；白结参与动作而不是只做装饰。
- 动态成品还需要时间轴、峰值停留、循环边界、小尺寸和平台文件检查；有拆件不是已经完成动画。

## 限制

- 技术Rig的组装参考不是正式外观判定图。
- 10张上传文件没有因上传而变成正式资产。
- 当前案例的1600×1600母版和240×240平台导出是本项目事实，不是所有平台的永久参数。

公开版不提供真实可编辑源或平台候选文件。若要复用这条路线，请先确认你自己的PSD、ORA或其他源文件确实可打开、可编辑且与当前母版一致。
