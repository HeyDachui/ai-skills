# 视觉不土保底 / Visual Safety Net

帮助AI新手把简单海报、PPT、页面或文档排版做到清楚、不土、能看。它是最低视觉保底，不冒充专业设计。

Help an AI beginner make a simple poster, slide deck, page, or document clear and presentable. This is a minimum visual safety net, not professional art direction.

## 怎么做 / What to do

1. 先判断是海报、PPT、简单页面还是文档排版，并查看真实产物；没有产物时给一个简单布局。  
   Identify the artifact type and inspect the real result; if none exists, propose one simple layout.
2. 第一眼只突出一个主要信息，标题、正文和次要说明要有明显层级。  
   Make one main message obvious at first glance, with clear hierarchy.
3. 保证文字能读：字号不过小、对比度够、信息不过挤、不被裁切。  
   Keep text readable: adequate size and contrast, reasonable density, and no clipping.
4. 让留白有目的、对齐一致、颜色数量克制；避免随机渐变、默认灰卡片和廉价模板感。  
   Use intentional spacing, consistent alignment, and restrained color; avoid random gradients, default grey cards, and cheap template patterns.
5. 不为了好看改掉事实、顺序或原意。  
   Do not change facts, sequence, or meaning for appearance.
6. 能直接修改时就修改；不能修改时，只给最重要的三项改法。  
   Improve the artifact directly when possible; otherwise give only the three most important changes.

## 退出边界 / Exit boundary

需要品牌系统、复杂UI、专业插画或视频视觉时，明确本 Skill 只能做保底，并转到专业流程。

If the task needs a brand system, complex UI, professional illustration, or video direction, state the limit and use a specialist workflow.
