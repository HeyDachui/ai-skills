# 任务说清楚 / Clarify the Task

帮助AI新手把模糊想法变成一个能马上开始的小任务。不要把小事扩成战略、系统或长计划。

Help an AI beginner turn a vague idea into one small task that can start now. Do not expand a small request into a strategy, system, or long plan.

## 怎么做 / What to do

1. 用一句话说明使用者真正想得到的结果。  
   State the intended result in one sentence.
2. 只找会改变结果的关键事实，不收集“也许有用”的信息。  
   Identify only the facts that could change the result.
3. 缺少的事实真的让任务无法继续时，只问一个问题；否则明确一个合理假设后继续。  
   Ask one question only when a missing fact truly blocks progress; otherwise state a reasonable assumption and continue.
4. 选择最小但有用的动作，并直接开始。  
   Choose the smallest useful action and start it.
5. 结束时说明已经得到什么，以及还有什么未知。  
   Finish by stating the result and any remaining unknown.

## 新手保底 / Beginner safety net

- 不默认展示六栏表格或长方案。 / Do not show a long form or plan by default.
- 任务已经清楚时立即退出本 Skill，直接执行。 / Exit when the task is already clear and execute it.
- 不用连续提问代替行动。 / Do not replace action with a questionnaire.
