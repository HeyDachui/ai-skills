# AI Beginner Six-Step Safety Net

**中文名：AI 新手六步保底 Skill 包**  
Version: 1.0.0 · 2026-07-29

Canonical slug: `ai-beginner-six-step-safety-net`

Public source: <https://github.com/HeyDachui/ai-skills/tree/main/skill-packs/ai-beginner-six-step-safety-net>

Six lightweight, bilingual Skills for people using AI for everyday work for the first time. Use only the one that matches the step where you are stuck:

1. `clarify-real-task` — turn a vague idea into one executable task.
2. `make-it-readable` — make existing text clearer while preserving facts.
3. `make-it-visual-good-enough` — make simple posters, slides, pages, or documents presentable.
4. `check-before-delivery` — inspect a real deliverable before claiming it is done.
5. `fix-after-failure` — repair a failed result from evidence instead of blind regeneration.
6. `handoff-to-next-person` — make a short, copyable handoff for another person, AI, or chat.

## Install or use

1. Download this folder through GitHub's **Code → Download ZIP**, or clone this repository.
2. Read the `SKILL.md` in the folder that matches the current problem.
3. If the AI host supports Skill folders, copy that one folder (including `agents/openai.yaml`) to the host's documented Skill location.
4. These files are instructions, not an automatic installer. Follow the host's own documentation for installation and support.

## Limits

This is an everyday safety net, not specialist legal, medical, academic, brand, or professional-design guidance. It does not promise professional-grade results or universal effectiveness for all beginners. Always inspect real outputs before delivering them.
