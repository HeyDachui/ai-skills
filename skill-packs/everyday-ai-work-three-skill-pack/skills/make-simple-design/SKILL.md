# 简单设计 / Everyday Design Basics

把普通内容做成一版干净、清楚、不土的日常设计。不要先给十种风格让使用者选择；根据内容选一个合理方向并直接做。

Turn ordinary content into one clean, clear, presentable everyday design. Do not begin with a menu of styles; choose one sensible direction from the content and make it.

## 怎么做 / What to do

1. 判断真实用途、使用位置和目标尺寸；只有缺少的格式会阻断制作时才问一个问题。  
   Infer the purpose, placement, and target size; ask one question only when a missing format truly blocks creation.
2. 保留原文、数字、名称和信息顺序。先确认一个主要信息，再安排标题、正文和辅助说明。  
   Preserve copy, numbers, names, and meaning. Choose one primary message, then arrange the title, body, and supporting text.
3. 选一个与内容相符的简单视觉方向。默认避免刻板蓝白科技模板、随机渐变、满屏卡片、廉价阴影和无意义装饰。  
   Choose one simple direction that fits the content. Avoid default blue-and-white tech styling, random gradients, card walls, cheap shadows, and decoration without a job.
4. 使用克制的颜色、清楚的字号层级、一致的对齐和有目的的留白。不要为了好看删掉承重信息。  
   Use restrained color, clear type hierarchy, consistent alignment, and intentional spacing. Do not remove important information for appearance.
5. 有合适工具时直接生成或修改真实文件；没有直接制作能力时，交付一份可立即执行的单一版式，不冒充已经生成文件。  
   Create or edit the actual artifact when tools allow. Otherwise deliver one implementation-ready layout and do not pretend a file was created.
6. 打开或渲染最终结果，检查文字是否读得清、元素是否裁切、层级是否明显、手机或目标尺寸下是否仍可用。  
   Open or render the final result and check readability, clipping, hierarchy, and the intended viewing size.

## 默认输出 / Default output

先交付可查看的设计结果或真实文件路径，再用一两句话说明：

- 这版突出什么；
- 仍未验证什么。

Deliver the viewable result or real file path first, followed by one or two sentences on the main emphasis and anything still unverified.

## 完成标准 / Done when

- 真实文件能够打开，或可执行版式已经完整到不需要再次选择风格；
- 标题、姓名、日期、数字、联系方式和其他承重信息与原材料一致；
- 没有文字裁切、遮挡、乱码、明显错位或缩小后无法识别的核心信息；
- 没有补造主办方、数据、人物、Logo或其他看起来像事实的内容。

The artifact opens, or the implementation-ready layout requires no further style choice; source facts remain intact; core information is readable without clipping or corruption; and no factual-looking content has been invented.

## 退出边界 / Exit boundary

如果任务实际需要PPT，使用`make-clean-slides`。需要品牌系统、复杂UI、专业插画或视频视觉时，说明本Skill只能做日常保底，并转到专业能力。

Use `make-clean-slides` for slide decks. For brand systems, complex UI, specialist illustration, or video direction, state this Skill's everyday-use limit and route to a specialist capability.
