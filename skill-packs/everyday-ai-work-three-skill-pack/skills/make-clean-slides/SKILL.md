# 规范PPT / Clean and Consistent Slides

把材料做成一套清楚、规范、好看的工作PPT。重点是讲明白、排整齐、能直接继续修改，不追求花里胡哨。

Turn source material into a clear, consistent, presentable work slide deck. Prioritize a readable story and editable output over decorative effects.

## 怎么做 / What to do

1. 从上下文判断听众、用途和交付格式；只有这些信息缺失会明显改变整套PPT时才问一个问题。  
   Infer the audience, purpose, and delivery format; ask one question only when the missing answer would materially change the deck.
2. 先确定这套PPT要讲清楚的一条主线，再根据材料决定页数。不要套固定页数，也不要把原文逐段贴进页面。  
   Identify one main story, then choose the slide count from the material. Do not force a fixed count or paste paragraphs onto slides.
3. 每页只承担一个主要任务：结论、解释、比较、步骤、证据或下一步。页面标题要能帮助读者理解，而不只是标注主题。  
   Give each slide one main job: conclusion, explanation, comparison, sequence, evidence, or next step. Use titles that advance understanding.
4. 全套统一字体、字号层级、颜色、页边距、网格、图表口径和页码。默认少颜色、少装饰，不堆相同卡片。  
   Keep typography, hierarchy, color, margins, grid, chart conventions, and page numbers consistent. Use restrained color and avoid repeated card layouts.
5. 保留事实、数字和不确定性。没有数据时不要画出像真实数据的图表；没有图片时不要用无关装饰图填空。  
   Preserve facts, numbers, and uncertainty. Do not invent charts or use irrelevant images as filler.
6. 有幻灯片工具时直接创建或编辑真实PPT文件；没有时交付完整逐页方案与统一视觉规范，并明确尚未生成`.pptx`。  
   Create or edit the real deck when slide tools are available. Otherwise deliver a complete slide-by-slide plan and visual system, clearly stating that no `.pptx` was produced.
7. 渲染并查看最终页面，至少检查标题溢出、正文过小、裁切、对齐、对比度、图表标注和页面节奏。  
   Render and inspect the deck for overflow, small text, clipping, alignment, contrast, chart labels, and pacing.

## 默认输出 / Default output

先给真实PPT路径或可查看预览，再简要说明：

- 这套PPT的主线；
- 已检查的内容；
- 尚未验证的内容。

Deliver the real deck path or viewable preview first, then briefly state the story, what was checked, and what remains unverified.

## 完成标准 / Done when

- 交付的是可打开、可继续编辑的幻灯片文件；没有制作工具时必须明确只交了逐页方案；
- 每页有一个可辨认的主要任务，全套顺序能够讲清同一条主线；
- 原材料中的名称、日期、数字、单位和结论没有被改写成另一件事；
- 全部页面已经渲染查看，没有溢出、裁切、重叠、乱码、过小正文或明显失衡；
- 没有用虚构数据、无关图片或装饰性图表制造“内容更丰富”的假象。

The deck opens and remains editable, each slide has one clear job, source facts remain intact, every slide has been rendered and visually checked, and no invented data or filler visuals are used.

## 退出边界 / Exit boundary

单张海报或页面使用`make-simple-design`。需要专业发布会级演示、复杂数据建模、品牌系统或专门动画时，转到相应专业能力。

Use `make-simple-design` for a single poster or page. Route professional keynote art direction, complex data modelling, brand systems, or specialist animation to the relevant capability.
