# Everyday AI Work Three-Skill Pack

**中文名：普通人 AI 办公三件套 Skill 包**  
Version: 1.0.0 · 2026-07-29

Canonical slug: `everyday-ai-work-three-skill-pack`

Public source: <https://github.com/HeyDachui/ai-skills/tree/main/skill-packs/everyday-ai-work-three-skill-pack>

Three small, bilingual Skills for people starting to use AI for ordinary office work. Pick only the Skill that matches the current job:

- `make-simple-design` — make a clear, presentable poster, social card, cover, or simple page.
- `make-clean-slides` — create or improve a clear, consistent, editable work slide deck.
- `write-clear-work-draft` — turn notes, a topic, or spoken material into a complete editable work draft.

This package contains exactly these three Skills. It does **not** include delivery checks, failure repair, or handoff; those are in the separate [AI Beginner Six-Step Safety Net](../ai-beginner-six-step-safety-net/README.md).

## Install or use

1. Download this folder through GitHub's **Code → Download ZIP**, or clone this repository.
2. Read the `SKILL.md` in the one folder that matches the current task.
3. If the AI host supports Skill folders, copy that one folder (including `agents/openai.yaml`) to the host's documented Skill location.
4. Use the Skill only for its stated scope. These files are instructions; they do not install themselves or guarantee that every AI host supports them.

## Limits

This is a practical starter pack, not a professional brand, data-analysis, legal, medical, academic, or specialist-writing system. It has not been proven through long-term natural use by every kind of AI beginner. Review real outputs before sending them.
