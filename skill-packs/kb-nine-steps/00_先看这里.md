# 九步搭好知识库

从第 1 步开始，把你正在做的一件事告诉 AI。

这套资料配合《知识库到底咋搭？九步》使用。每步都有可直接粘贴的短提示词，以及包含完整步骤的 `SKILL.md`。

| 文件夹 | 一句话 | 你要给什么 | 得到什么 |
| --- | --- | --- | --- |
| [01_需求访谈](01_需求访谈/) | 先问清知识库要帮你做什么 | 你的工作、具体任务和访谈回答 | 用途、人机分工、错误底线和搭建建议 |
| [02_简单搭建](02_简单搭建/) | 先搭一个能用的小库 | 单一工作、资料范围、整理周期 | 文件夹结构、一份规范、一段整理指令 |
| [03_卡片模板](03_卡片模板/) | 用固定字段分清原文、补充和未知 | 一条知识、原文和来源信息 | 内容一致的 Markdown 卡与 JSON 对象 |
| [04_拆分制卡](04_拆分制卡/) | 把长资料拆成完整的候选知识卡 | 长资料、来源和日期 | 按事实、理论、观点、技巧、经验区分的候选卡 |
| [05_复查周期](05_复查周期/) | 有变化就复核，定期检查作补充 | 卡片、资料日期和工作领域 | 复查周期表、事件触发条件和待核实项 |
| [06_强制检索](06_强制检索/) | 遇到真实知识需要时，先查库再使用 | 当前问题、目标、条件和可访问的知识库 | 检索规则、读源与引用记录 |
| [07_保真检查](07_保真检查/) | 请另一位 AI 对照原文查偏差 | 原文、候选卡和核对范围 | 保真差异表、修正建议和待核实项 |
| [08_卡片评分](08_卡片评分/) | 分项评分，先守住忠于原文的底线 | 当前问题、使用时间、候选卡及原文 | 四项评分、理由、能否使用及分歧记录 |
| [09_复盘回写](09_复盘回写/) | 把实际工作中的新经验写回库 | 原问题、工作结果、旧卡和新证据 | 新候选卡、旧卡修订、采用与效果记录、原题复测 |

## 用法一：直接粘贴短提示词

打开对应文件夹里的 `提示词.md`，复制全文到 ChatGPT、Claude、Codex 等聊天 AI。将【】中的内容换成自己的工作，并提供要求的资料。九份提示词保留片中上屏文字。

AI 需要的原文和知识库内容，要上传或明确提供可读取的位置。对话工具只能使用它实际能访问的材料；涉及保存文件的步骤，可以让它输出内容，由你保存。

## 用法二：安装完整 Skill

支持 Skill 的工具可以读取完整步骤。每个文件夹都包含 `SKILL.md` 和 `agents/openai.yaml`。安装方法随工具而异。

**Codex：**把整个资料包放进自己的项目，对 Codex 说：

> 请读取这套资料包，在当前项目中运行“安装技能.ps1”，安装九份技能到当前项目的 .agents/skills，不要覆盖已有同名技能。安装后查看技能列表，确认九个名称都能发现。

Windows 上也可以在自己的项目目录中运行：

```powershell
& '.\资料包\安装技能.ps1'
```

脚本需要 PowerShell，只复制九份技能到当前工作目录的 `.agents/skills`，以英文技能名建立文件夹。发现同名目录时会在复制前停止。其他系统可手动复制九个技能文件夹，将目录名改为各 `SKILL.md` 开头的 `name`。

Codex 会自动检测技能变化；没有显示时重新启动 Codex，并查看技能列表。默认目录及配置参见 [OpenAI 官方技能说明](https://learn.chatgpt.com/docs/build-skills)。

**Claude 等工具：**按所用工具的技能安装入口导入完整文件夹；需要目录名时，使用 `SKILL.md` 开头的英文 `name`。本包脚本默认面向 Codex 的项目目录；也可通过 `-Destination` 指定所用工具文档要求的项目技能目录。暂不安装时，直接提供对应 `SKILL.md`，请 AI 读取并执行。

开始时可以说：

> 我想为【工作】搭一个知识库，最近要完成【具体任务】。请使用 $needs-interview，从第 1 步开始，一题一题访谈我。

这是模板，按自己的工作调整，周期和评分只是辅助。
