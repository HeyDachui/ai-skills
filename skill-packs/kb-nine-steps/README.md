## 获取与使用

在仓库首页选择 **Code → Download ZIP**，解压后找到 `skill-packs/kb-nine-steps`；也可以克隆仓库后进入这个目录。

打开某一步的 `提示词.md`，复制到聊天 AI 并替换【】中的内容即可开始。支持 Skill 的工具可安装完整文件夹，或直接读取 `SKILL.md`。Windows 安装脚本 [安装技能.ps1](安装技能.ps1) 默认安装到当前项目的 `.agents/skills`，遇到同名目录先停止，不覆盖。具体操作见导读。
